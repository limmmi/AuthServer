## 二、详细执行步骤

### 阶段 1：程序入口（main.cpp）

```cpp

```

### 阶段 4：请求处理循环

#### 4.1 新连接处理

```
epoll 返回 listenFd 有事件
        │
        ▼
HandleNewConnection()
    │
    ├── accept() 接受新连接
    ├── SetNonBlocking() 设为非阻塞
    ├── epoll_ctl(ADD) 加入 epoll
    └── clientBuffers_[fd] = "" 初始化缓冲区
```

**代码位置**: `Server.cpp:117-140`

#### 4.2 客户端请求处理

```
epoll 返回 clientFd 有数据
        │
        ▼
HandleClientData(fd)
    │
    ├── read() 读取数据到缓冲区
    ├── 检查是否收到完整 HTTP 请求（查找 \r\n\r\n）
    ├── ParseHttpRequest() 解析 HTTP 请求
    │       ├── 解析请求行（GET /api/login HTTP/1.1）
    │       ├── 解析请求头
    │       └── 解析请求体
    │
    ├── RouteRequest() 路由分发
    │       ├── /api/register → HandleRegister()
    │       ├── /api/login → HandleLogin()
    │       ├── /api/admin/register → HandleAdminRegister()
    │       ├── /api/user/info → HandleGetUserInfo()
    │       └── /api/health → HandleHealth()
    │
    ├── 调用对应的处理函数
    │       └── 可能操作数据库（AuthService）
    │
    ├── BuildHttpResponse() 构造响应
    ├── write() 发送响应给客户端
    └── CloseClient() 关闭连接
```

**代码位置**: `Server.cpp:142-200`

---

### 阶段 5：具体接口处理流程

#### 5.1 用户注册流程

```
HandleRegister(request)
    │
    ├── ParseJson() 解析请求体
    │       └── {"username":"xxx", "password":"xxx"}
    │
    ├── authService_->Register(username, password)
    │       │
    │       ├── 检查用户名/密码长度
    │       ├── db_.Exists(username) 检查用户是否存在
    │       ├── GenerateUserId() 生成新用户ID
    │       │       └── db_.Put("__max_user_id__", id)
    │       ├── Crypto::HashPassword() 密码哈希
    │       │       └── PBKDF2 算法生成哈希
    │       ├── 第一个用户？→ role = ADMIN : NORMAL
    │       └── db_.Put(username, "id:role:hash")
    │
    └── 返回 JSON 响应
```

**代码位置**: `Server.cpp:236-260`, `AuthService.cpp:135-172`

#### 5.2 用户登录流程

```
HandleLogin(request)
    │
    ├── ParseJson() 解析请求体
    │       └── {"username":"xxx", "password":"xxx"}
    │
    ├── authService_->Login(username, password)
    │       │
    │       ├── db_.Get(username) 获取用户数据
    │       │       └── "id:role:hash"
    │       ├── ParseUserData() 解析数据
    │       ├── Crypto::VerifyPassword() 验证密码
    │       │       └── PBKDF2 哈希比较
    │       └── GenerateJWT(userId, role)
    │               └── JWT::GenerateWithPayload()
    │                       ├── Base64UrlEncode(Header)
    │                       ├── Base64UrlEncode(Payload)
    │                       ├── RSA_sign() 签名
    │                       └── 组合成 JWT 字符串
    │
    ├── GetUserInfo() 获取角色信息
    └── 返回 JSON（含 token, role, userId）
```

**代码位置**: `Server.cpp:202-234`, `AuthService.cpp:101-133`

#### 5.3 管理员注册流程

```
HandleAdminRegister(request)
    │
    ├── ParseJson() 解析请求体
    │       └── {"username":"xxx", "password":"xxx", "role":"admin", "admin_token":"xxx"}
    │
    ├── authService_->RegisterWithRole(...)
    │       │
    │       ├── JWT::ParsePayload(admin_token) 解析 Token
    │       ├── 检查 role 字段是否为 "admin"
    │       ├── 验证失败？→ 返回 false
    │       └── 验证通过？→ 执行注册逻辑（同普通注册）
    │
    └── 返回 JSON 响应
```

**代码位置**: `Server.cpp:262-290`, `AuthService.cpp:174-208`

### 阶段 6：数据库操作（Database）

```
所有数据库操作通过 Database 类封装：

Database::Put(key, value)
    └── leveldb::DB::Put() 写入键值对

Database::Get(key, value)
    └── leveldb::DB::Get() 读取键值对

Database::Exists(key)
    └── Get() 检查 key 是否存在

Database::Delete(key)
    └── leveldb::DB::Delete() 删除键值对
```

**代码位置**: `Database.cpp`

---

### 阶段 7：程序退出

```
收到 SIGINT (Ctrl+C) 或 SIGTERM
        │
        ▼
SignalHandler(sig)
    │
    ├── g_server->Stop()
    │       │
    │       ├── running_ = false 设置停止标志
    │       ├── 遍历 clientBuffers_ 关闭所有客户端 fd
    │       ├── close(epollFd_) 关闭 epoll
    │       └── close(listenFd_) 关闭监听 socket
    │
    └── main() 继续执行，程序结束
```

**代码位置**: `main.cpp:14-22`, `Server.cpp:102-114`

## 七、总结

AuthServer 采用 **单线程 Reactor 模型**，执行流程清晰：

1. **启动阶段**：解析参数 → 加载私钥 → 打开数据库 → 启动网络服务
2. **运行阶段**：epoll 事件循环 → 接受连接 → 解析 HTTP → 业务处理 → 返回响应
3. **退出阶段**：信号触发 → 关闭连接 → 释放资源 → 程序结束

整个程序无多线程竞争，无需加锁，简单稳定。
